# Car model credits

`car_sedan.glb`, `car_sport.glb`, `car_suv.glb`

These are third-party low-poly car models, converted to glTF with `obj2gltf`.
The conversion did not carry over the source metadata, so the glTF `asset`
block has no author or copyright field.

**Source and licence still to be filled in before this repository is made
public.** Most free model libraries (Kenney, Quaternius, Poly Pizza and
similar) allow redistribution but ask for attribution, and some require it.
Until the origin is confirmed, treat these three files as not cleared for
redistribution.
