# Audio assets

Place the garbage truck song here as `garbage-truck.mp3`.

The truck component plays `/audio/garbage-truck.mp3` on loop using
spatial (3D positional) audio while it drives through the garage.
If the file is missing, the truck still drives — it's just silent.

The song "Gadi Wala Aaya Ghar Se Kachra Nikaal" is a copyrighted
Hindi children's song. You must provide the audio file yourself;
it is not included in this repository for licensing reasons.
